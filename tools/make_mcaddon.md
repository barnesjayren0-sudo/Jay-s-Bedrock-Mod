# Build NestCord.mcaddon

1. Put a **128×128 PNG** named `pack_icon.png` in both `BP/` and `RP/`.
2. Zip contents of `BP` → `NestCord_BP.mcpack` (zip root = manifest.json level).
3. Zip contents of `RP` → `NestCord_RP.mcpack`.
4. Zip both `.mcpack` files together → rename to `NestCord.mcaddon`.
5. GitHub → Releases → upload `NestCord.mcaddon`.

Phone: open the `.mcaddon` to import both packs.
